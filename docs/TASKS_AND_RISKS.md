## 二、风险控制矩阵 (Risk Matrix)

| 风险项 | 风险等级 | 潜在影响 | 防范与缓解策略 |
| :--- | :---: | :--- | :--- |
| **设备数据造假/失真风险** | 高 | 误导家庭物理安全判断，损害系统信任度 | 实施 ADR-003，严格要求未连接物理设备显示 `offline`，禁止造假遥测；仅在隔离的 `is_demo=True` 沙箱中提供模拟数据，UI高亮标记。 |
| **端口冲突与孤儿进程** | 中 | 本地启动失败、服务无法关闭或占用 8000/5173 | 启动脚本预先检测端口占用；绑定指定 PID 文件；Windows 脚本支持统一进程树清理。 |
| **数据库文件锁与并发** | 中 | 多线程/异步读写造成 SQLite `database is locked` | 强制开启 SQLite `WAL` 模式；配置 `busy_timeout=5000`；SQLAlchemy 连接池优化。 |
| **凭据泄漏与非授权访问** | 高 | 局域网恶意攻击、家庭隐私外泄 | 默认仅绑定 `127.0.0.1`；敏感凭据严禁打印到日志或前端源码；密码 Bcrypt 加密；接口严格校验 JWT。 |
| **Python 3.14 兼容性** | 低 | 部分第三方二进制库缺少 wheel | 优先选用纯 Python 或支持 ABI3 的标准库（fastapi, pydantic, pyjwt, sqlalchemy 已实测验证无故障）。 |
