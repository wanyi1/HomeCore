# ADR-0003: 设备真实状态诚实原则与独立隔离演示模式设计

## 状态
已接受 (Accepted)

## 背景
智能家居中枢必须具备极高的可信度与安全性。若系统伪造设备在线、虚拟功率遥测或假冒控制成功，将严重误导用户对物理家庭环境的判断，甚至引发安全隐患。
同时，在缺少物理外设的开发或展示阶段，又需要能够验证完整的业务流。

## 架构决策

1. **真实状态原则**：
   - 凡无法连接、网络不可达、认证失效或适配器超时的设备，其状态必须如实标记为 `offline`（未连接/离线），UI 显示专属离线警示标志，严禁伪造心跳或在线态。
   - 禁止在未连接实体传感器或计量插座的情况下伪造虚假功率、电量、温湿度读数。缺测时明确呈现“无数据/未采集”。

2. **独立演示模式 (Demo Simulator)**：
   - 提供独立标记的演示模拟器（`is_demo: true`）。
   - 演示设备在列表、详情卡片与日志中均以高对比度标签 **【演示设备】** 或 **【模拟】** 明确区分。
   - 真实设备与演示设备数据流严格隔离，演示开关与调光仅在模拟适配器内存/沙箱中流转，绝不混淆真实审计。

3. **操作审计链路**：
   - 每次对设备的控制指令（开、关、调节、场景触发）均记录审计日志（Operator, DeviceId, Command, Payload, Result, Timestamp），杜绝静默操作。
